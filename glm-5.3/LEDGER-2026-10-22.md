# Tensor/allocation ledger + IQ2_S roofline (ROADMAP ranks 2 and 5) - 2026-10-22

Scope: the two backlog items that need no healthy-RAM machine. No kernel edits, no rebase, no re-baseline.

| confirmation | one arm for the best candidate only, same discipline | ~3 min |

Decision gate (ROADMAP rank 2): a placement that keeps `blk.44.ffn_*_exps` in VRAM with >= 1 GiB free on every card
at the `-ub 1024` peak. If no placement-only variant clears it, report the exact byte deficit per card (input to
rank 3, the one-layer mixed quant).

Rank 5 plan: roofline from bytes actually read per decoded token (8 of 288 experts x 3 matrices per MoE layer, by

### Placement search (offline model = exact weights + measured per-layer KV/RS + measured buffers)

- Whole-layer cuts (`-ts` only): impossible (best min free at peak negative).
- Attention/FFN half-layer cuts: best min free 386 MiB - fails the 1 GiB gate (an FFN half is still 2.4 GiB).
- Expert-tensor cuts (a boundary may fall between a layer's gate / up / down expert tensors - still one crossing,
  the scheduler copies the split's inputs once): **best min free 1484 MiB predicted**. Chosen: placement A.

Placement A (llama device index):

```
-ts 28.7,23.4,23.4,24.5                     # SYCL0 blk 0-13, SYCL1 14-24, SYCL2 25-35, SYCL3 36-45 + output
-ot blk\.13\.ffn_(up|down)_exps\.weight=SYCL1
-ot blk\.24\.ffn_down_exps\.weight=SYCL2
# and no "blk\.44\.ffn_.*_exps\.weight=CPU" - every expert on a GPU
```

Measured (arm `ledger-placeA`, `-lv 4`): host model buffer 496.3 MiB (token_embd only); compute buffers moved with
the cuts (SYCL2 1175.7 -> 1440.9), steady 29.13 / 30.08 / 30.23 / 29.48 GiB, **peak card 30.48 GiB during the 31k
prompt = 1.30 GiB free** -> gate passed (>= 1 GiB on every card).

6 experts per call (DeepSeek perf case; per-expert matrix identical to GLM's). **Cost is linear in (token, expert)
entries** - no weight reuse across the tokens of a verify window.

### Share of a production verify step

Per token-row, per layer, 8 experts: IQ2_S gate ~109 us + up ~109 us (IQ2_XS scaled by bytes, 82 vs 74 B/block) +
IQ3_XXS down ~87 us = ~305 us -> 12.8 ms over 42 layers. A step verifies ~2.74 rows (1 + 1.74 drafted), so routed
experts are **~35 ms of the 94.2 ms step (~37%)**.

Amdahl ceilings for rank 6:

- ROADMAP go gate, +15% on the routed operator: ~4.6 ms/step = **+5.1% end to end** (bar: +3%) - passes.
- gate/up at reordered-Q4_K level (~400 GB/s): ~12.9 ms/step = ~+16%.
- all routed kernels at ~450 GB/s: ~17 ms/step = ~+22%.

### Compiler inspection (AOT image extracted from `ggml-sycl.dll`, `.ze_info` kernel metadata)

The fork's kernels are AOT-compiled (an IGC dump env produced nothing), so the image was pulled with
`clang-offload-extract` and read with `ocloc disasm`. For every v3 MoE variant (NSG 4/8 x RPS 1/2/4):

- SIMD16, 128-GRF mode, one barrier, **no spills, no scratch** - register pressure is not the limiter.
- **IQ2_S v3: 5 x RPS indirect stateless (global) loads; IQ3_XXS v3: 1 x RPS.** The IQ2_S 8 KiB grid is gathered
  from global memory (staging it in SLM lost to bank conflicts on the random 10-bit index); IQ3_XXS's 2 KiB grid is
  in SLM. That matches the measured gap (197 vs 295 GB/s): **the IQ2_S codebook gather is the identified limiter**.
- Both types stage every weight byte global -> SLM -> registers and re-stage the activation vector in every
  work-group.

### Verdict

Rank 5 gate met: a real limiter is identified and rank 6 clears its ceiling (+5% at the go gate, up to ~+16-22%).
Rank 6 is kernel work, so it waits for the healthy-CPU rule to lift - although it is single-card and does not depend
on host RAM, which is the operator's call. Candidate first steps, one variable at a time:

1. IQ2_S grid compression: every grid byte is one of three magnitudes, so the 1024-entry table fits as 2-bit codes
   (2 KiB of uint16) in SLM with a shift/select expansion - a different bank footprint from the failed 8 KiB staging.
2. Expert-reordered storage (SoA per expert) for direct wide loads, dropping the SLM round trip.
3. Weight reuse across a verify window (rows read once, dotted against every routed token) - the earlier grouped-
   verify attempt was a different design (owner work-group per expert) and lost; re-test only with a new mechanism.

Rank 3 (one-layer mixed quant) no longer has a purpose - placement A already fits every expert - and drops down the
backlog.
