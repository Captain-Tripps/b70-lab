## Gotchas (non-negotiable, all proven the hard way)

- scp/SFTP to the bench box hangs -> pipe base64 via stdin; "base64: invalid input" on the pipe is harmless,
  verify with md5sum both sides (bytes always land exact).
- Two `cmd.exe /c` launches back-to-back in one bash-over-ssh script: the second silently never runs.
  One interop call per ssh call.
- `config.windows.yaml` is CRLF; strip `\r` before base64-piping to bash; sed `$`-anchors fail silently.
- `'@` at line start kills PS here-strings; avoid `$_` in bash-heredoc PS one-liners (write helper .ps1 files).
- Mock exes for tests: renamed ping.exe exits on unknown switches; renamed powershell.exe dies (assemblies);
  compile with `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`.
- Judge RAM by working set / free physical / PDH per-adapter Dedicated Usage - never private bytes
  (B showed 123 GB private vs 4.5 GB working set).
- `-ts` maps to cards in REVERSE order; ub ladder costs ~0.5 GB/card per 256 step; ub never changes decode.
